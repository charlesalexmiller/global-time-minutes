# Privacy Policy for Global Time Minutes

**Last updated: November 20, 2026**

Global Time Minutes is a Chrome extension that displays the current minute for a selected time zone directly in the Chrome toolbar.

## 1. Information We Collect

Global Time Minutes does **not collect, upload, sell, or share personal information**.

The extension does not use analytics, advertising trackers, or external data-collection services.

The extension does not request access to browsing history, tabs, cookies, website content, or other websites.

## 2. Information Stored Locally

Global Time Minutes stores the following extension settings locally in your browser using Chrome's `chrome.storage.local` API:

- Selected language
- Selected time zone
- Leading-zero preference
- Font weight preference
- Theme preference

These settings are used only to provide and customize the extension's minute display.

The stored settings are not transmitted to the developer or to any external server.

## 3. Time Zone and Language Information

The extension may use the browser's language and system time zone information to determine appropriate default settings and display the selected time correctly.

This information is processed locally by the extension and is not sent to the developer or any external server.

## 4. Permissions

Global Time Minutes requests the following Chrome permissions:

### Storage

The `storage` permission is used to save and retrieve the extension's settings locally through `chrome.storage.local`.

### Alarms

The `alarms` permission is used to run the extension's background update once per minute. This keeps the minute displayed in the Chrome toolbar up to date.

The alarms permission is not used to send notifications or reminders.

## 5. Data Sharing

Global Time Minutes does not sell, share, or transfer user information to third parties.

The extension does not operate its own server and does not transmit extension settings or time zone information to external servers.

## 6. Data Security

Because the extension does not transmit user settings to external servers, Global Time Minutes does not maintain a remote database containing user information.

Settings remain in Chrome's local extension storage.

## 7. Changes to This Privacy Policy

If the privacy practices of Global Time Minutes change, this Privacy Policy will be updated accordingly.

The latest version of this Privacy Policy will always be available at this page.

## 8. Contact

For questions or concerns regarding this Privacy Policy or Global Time Minutes, please contact the developer through the contact information provided on the Chrome Web Store listing.
